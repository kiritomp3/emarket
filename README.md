# PowderLab MVP

Интерактивный прототип магазина порошков для 3D-печати.

Адрес: https://boost-gta6.ru/powderlab/

## Изоляция и нагрузка

Статические файлы обслуживает существующий Nginx. Отдельных сервисов, контейнеров, портов, Node.js-процессов и базы данных нет. WebGL-сцена работает в браузере. Используется отдельная директория /var/www/powderlab и версионированные релизы в /var/www/powderlab-releases. Существующий сайт в корне домена сохраняется.

## Структура

- public/: готовый сайт, локальные шрифты и Three.js.
- deploy/nginx-location.conf: отдельный маршрут внутри существующего HTTPS-сервера.
- scripts/deploy.sh: загрузка нового релиза и переключение симлинка; без установки зависимостей и без изменения Nginx.
- DESIGN.md: дизайн, реализованные возможности и ограничения.

## Обновление

Из корня репозитория: `bash scripts/deploy.sh root@77.91.102.52`.
Скрипт использует имеющийся SSH-доступ. Паролей и ключей в репозитории нет. Первичная настройка маршрута Nginx выполняется отдельно с резервной копией и проверкой конфигурации.

Для просмотра локально: запустить статический HTTP-сервер из директории, содержащей public как powderlab (адреса сайта имеют базовый путь /powderlab/).

## Ограничения

Ассортимент демонстрационный. CMS, приём заявок, оплата и CRM не подключены. Запрос скачивается файлом и не отправляется поставщику. Индексация закрыта метатегами и HTTP-заголовком. Открытая публикация предназначена для просмотра прототипа, не для запуска продаж.
